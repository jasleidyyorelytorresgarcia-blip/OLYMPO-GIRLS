OLYMPO*GIRLS - Documento de Requerimientos

1. Requerimientos Funcionales

RF1: El sistema debe mostrar un catálogo de productos con nombre, descripción, precio e imagen.

RF2: El sistema debe permitir agregar productos al carrito.

RF3: El sistema debe mostrar el contador del carrito en el menú.

RF4: El sistema debe permitir ver el carrito, el total y vaciarlo.

RF5: El sistema debe permitir crear un pedido al comprar.

RF6: El sistema debe permitir iniciar sesión y guardar la usuaria.

RF7: El sistema debe permitir contactar por WhatsApp para pedidos.

RF8: El sistema debe mostrar la sección de la creadora.

2. Requerimientos No Funcionales

RNF1: El diseño debe ser responsive, se debe adaptar a celular y computador.

RNF2: La interfaz debe usar colores rosado, palo de rosa y vino, estilo Grecia antigua.

RNF3: La página debe cargar rápido y sin errores.

RNF4: El código debe estar separado en HTML, CSS y JS.

RNF5: El carrito debe guardarse con localStorage aunque se recargue la página.

3. Historias de Usuario

HU1: Como clienta quiero ver los productos para elegir el que quiero.

HU2: Como clienta quiero agregar al carrito para comprar varios.

HU3: Como clienta quiero iniciar sesión para sentirme parte del Olimpo.

HU4: Como clienta quiero escribir por WhatsApp para hacer mi pedido.
